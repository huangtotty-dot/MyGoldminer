## 三、周一盘中（9:30 — 15:00）

### 3.1 策略行为预期

| 时间 | 事件 | 说明 |
|------|------|------|
| 09:31 | **建底仓** | 市价买入 ≈800 股华工科技（资金×50%/开盘价），飞书收到 `🔵 成交 BUY` |
| 09:31-09:35 | **买入隔离** | 开盘 5 分钟不产生买入信号（防开盘量能失真） |
| 09:35-14:50 | **正常交易** | 信号引擎评估每分钟 bar，触发 BUY_LOW / SELL_HIGH |
| 14:50-15:00 | **尾盘归位** | 持仓超底仓 → 强制卖出归位 |

### 3.2 飞书通知类型

| 通知 | 含义 | 示例 |
|------|------|------|
| 🟢 低吸信号 | engine 产生 BUY_LOW 信号 | `华工科技(000988) 评分:55分 持仓:800股` |
| 🔴 高抛信号 | engine 产生 SELL_HIGH 信号 | `华工科技(000988) 评分:72分` |
| 🔵 成交 | 买卖单全部成交 | `买入 300股 @ 105.50 成交后持仓:1100股` |
| ❌ 委托被拒 | 柜台拒单（资金不足等） | `买入 300股 原因: 资金不足` |
| 🛑 KILL_SWITCH | 急停文件触发 | 放置 KILL_SWITCH → 策略停止开仓 |

### 3.3 风控护栏

| 规则 | 触发条件 | 行为 |
|------|---------|------|
| 仓位上限 | 单票市值 > 总资产 80% | 拦截买入，日志+事件记录 |
| 卖出地板 | 持仓 ≤ 底仓 50% | 拦截卖出 |
| PANIC 止损 | 浮亏 > max(-5×日ATR, -12%) | 触发恐慌卖出 |
| uni_down 熔断 | 大盘判定为单边下行 | 禁止所有买入 |
| KILL_SWITCH | `E:\06_T\t_io\gm_bridge\KILL_SWITCH` 存在 | 禁止新开仓（平仓不禁） |

### 3.4 ⚠️ 重要：周一只看不跟

- **周一不实盘跟随**，目标是验证链路
- 观察信号节奏，熟悉通知格式
- 记录任何异常（信号频率、价位偏差、通知延迟）

### 3.5 紧急停止

如果发现策略异常：

1. 在 `E:\06_T\t_io\gm_bridge\` 下创建空文件 `KILL_SWITCH`
2. 策略会在下一分钟停止新开仓（已持仓可继续卖出）
3. 飞书收到 `🛑 KILL_SWITCH` 通知
4. 复盘后手动删除该文件恢复

命令行操作：
```bash
# 急停
echo "" > "E:\06_T\t_io\gm_bridge\KILL_SWITCH"

# 恢复（复盘后）
rm "E:\06_T\t_io\gm_bridge\KILL_SWITCH"
```
