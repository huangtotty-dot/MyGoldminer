## 三、日线上下文与个股趋势状态机

- **构建**：`_refresh_daily_ctx`，每日首根 bar 拉 120 日日线（`history_n`，end_time=昨日 15:00 防当日未收盘污染），按 `(日期|代码)` 缓存（main.py:211-293，N18 修复后按票隔离）。
- **产出字段**：`daily_ma5/10/20`、`daily_atr`（TR14/close，下限 0.02）、`daily_prev_close`、`daily_breakdown_risk`（close < MA20×0.985）、`daily_overheated`（close > MA20×1.08）、`_m2_*` 门槛三指标。
- **个股四态**（main.py:267-277）：
  - `TREND_BREAKDOWN`：daily_breakdown_risk=True（收盘 < MA20×0.985）
  - `TREND_DOWN`：收盘 < MA5 且 MA5 斜率 < 0
  - `TREND_UP`：收盘 > MA5 且 MA5 斜率 > 0
  - `TREND_RANGE`：其余
  - 每日一盘，日内不翻转。
- **消费方**：G3 熔断（BREAKDOWN 禁买/DOWN 禁 ADD_POS）、底仓延迟、TREND_EXIT、引擎 buy_blocks。

## 四、大盘态势（index_regime，回测降级版）

- **接口**：`detect_index_regime(as_of, mode)` → regime ∈ {uni_up, range, uni_down} + score + ctx（analysis/index_regime.py:768-771）；init() 预取指数日线注入缓存。
- **评分**：趋势分×0.6 + 环境分×0.4 → Hurst 修正（>0.6 时×1.2，<0.4 时×0.8）→ SHARP 叠加（±40，|sharp|≥32 触发）→ 衰竭修正（|s|>37.5 时×0.7）。
- **状态机**：range 中 |s|≥25 连续 2 天 → uni_up/down；|s|<15 → 退回 range；当日指数涨跌 ≥±1% → K-day 强制跃迁。
- **⚠ 三个已知降级**（子代理审查发现）：
  1. **状态机无持久化**（index_regime.py:719-720 硬编码 prev=RANGE/days=0）→ `enter_confirm_days=2` 永不满足，**uni_up/uni_down 实际只能靠当日 ±1% K-day 触发**；
  2. 趋势维度 reg_r2/er/aroon 三个子因子（合计权重 0.32）定义了但完全不计算；
  3. 环境维度 breadth/nhnl/qvix 全部降级，实际只剩量能一项（0.25×0.4）。
- **消费方**：引擎大盘因子分（uni_up→买1.0/卖0.2，range→0.5，uni_down→买0.0/卖1.0）、G2 uni_down 禁买（main.py:608-610）、`index_gate_advice` 透传。
- **仓位系数表**（定义但 main.py 未直接消费）：uni_down 0.6 / range 1.0 / uni_up 1.1。

## 五、信号引擎（signals/engine.py）

### 5.1 评分公式（买卖对称，7 因子 sigmoid 加权）

`因子分 = raw(0~1) × 100 × 权重`，sigmoid 形式 `1/(1+e^{-slope·(x-center)})`，z 值超 ±100 截断。满分合计 **92**（非 100，position 因子未接入），再 min(score,100)。

| 因子 | 权重 | 买入侧 raw | 卖出侧 raw |
|---|---|---|---|
| VWAP 偏离 | 0.20 | (vwap-price)/price/ATR，center=0.5 slope=2.0 | (price-vwap)/vwap/ATR，center=0.5 slope=1.5 |
| 形态（影线） | 0.20 | 长下影 center=0.3 slope=8.0 | 长上影 center=0.4 slope=6.0 |
| 大盘态势 | 0.20 | uni_up=1.0/range=0.5/uni_down=0.0 | uni_down=1.0/range=0.5/uni_up=0.2 |
| RSI | 0.12 | sigmoid(35-rsi, c=3, s=0.5) | sigmoid(rsi-78, c=3, s=0.5) |
| MACD | 0.08 | hist<0 且回升：min(1,\|mh\|/\|pmh\|) | hist>0 且萎缩：min(1, mh/(mh-pmh)) |
| 量能 | 0.08 | vol_ratio，center=1.2 slope=4.0（raw≤0.05 丢弃） | 同左（双向共用） |
| EMA 趋势 | 0.04 | ema_spread 改善 sigmoid(c=0.0005, s=500) | ema_spread 恶化 同参 |

### 5.2 RiskManager 一票否决（engine.py:257-284）

- 特征为空 → 全拒；
- **sell_block**：`day_amplitude<0.002 且 10:00 后`（死水禁卖）；
- **buy_block**：`daily_breakdown_risk` / `is_gap_down_no_reversal` / `daily_overheated` / `index_regime==uni_down` / 盘中 I1、I4 告警。

### 5.3 信号产生（evaluate，engine.py:468-540）

- **卖出优先**：sell_score ≥ notify_sell_threshold（全局 65 / 000988=63）且无 sell_block 且冷却到期且当日卖出次数 < max_sell_times（全局 3 / 000988=2）→ SELL_HIGH；买卖同 bar 同时达标只卖不买。
- **买入**：buy_score ≥ notify_buy_threshold（全局 68 / 000988=43）且无 buy_block 且冷却到期且当日买入次数 < max_buy_times（全局 1 / 000988=3）→ BUY_LOW。
- **冷却**：成交回调 `record_trade_action` 写入，buy/sell_cooldown = now + cooldown_minutes（全局 30 / 000988=25）；跨日 `_check_date_reset` 清空 12 类状态字典。
- **死代码/死参数**：FACTOR_WEIGHTS 中 9 键未使用（含 stop/take_profit_atr_mult 等）；`is_double_top` 恒 False；`extract_5min_features` 空函数；engine.py:512-513 重复分支。

### 5.4 关键特征（FeatureExtractor）

- `atr`：14 根 1 分钟 K 线 (h-l) 均值/price，下限 0.002，不足 14 根取 0.02；
- `is_deep_loss`：`profit_pct < max(-5×daily_atr, -0.12)`（N9：ATR 浮动线下限 -12%）——**engine 内只算不用，由 main.py 消费产生 PANIC_SELL**；
- `is_strong_uptrend`：5/10/20 均线多头 + 自当日低点反弹 >3×ATR + price > VWAP×1.005（N1：不再禁卖，只降分）；
- f15_rsi：15 分钟 RSI 周期 6。

## 七、买入执行链

按序：kill_switch 检查 → 日买入计数 → **N15 现金 fail-closed**（读不到现金则 available_cash=0 每 bar 生效，WARN 仅一次）→ **N16 单票预算**（`_stock_budget = available_cash/4` 等权 25%，TODO(PhaseD) 趋势加权；estimated_equity = budget + 持仓市值）→ **N10 仓位上限**（max_single_position_pct=0.80，target_t = max(预算×0.8 换算股数, base_ref, 现持仓)）→ sizer 分档 → 现金预检（max_by_cash = 现金×95%）→ 下单。

**sizer 分档**（signals/position_sizer.py）：
- 买入：strength=score-threshold；≥10 → target_t×30%（000988=27%）；≥5 → 20%；<5 → 10%；下限 100 股，上限 max_buyable=target_t-现持仓（⚠ 先 min 后 max(100)，max_buyable<100 时会顶破上限买 100 股——低优先级缺陷）；
- 卖出：第 1 次 strength≥10/≥5/<5 → total_t 的 40%/30%/20%；第 2 次 ≥5 → 40% 否则 20%；第 3 次起 15%；下限 100 股，上限 available。

## 十二、KPI 实验指引（每次实验必守）

### 12.1 实验原则
1. **单变量**：一次实验只改一处（一个参数/一个结构），禁止打包——否则归因不可能；
2. **基线对照**：固定基线 = fix8（+8.06%/MDD -8.27%/66 笔/通道分布见 N28 验收值）；任何实验产出与基线的**逐笔差异归因清单**；
3. **结构问题优先于数值问题**：复盘发现"这单不该买/卖"→ 修结构；"点位差一点"→ 才轮到调参；
4. **过拟合警戒**：4 票 × 3 个月是薄样本，任何参数改善须在三窗口（fix2/fix3/fix4 场景）中至少两个成立才认可；
5. **铁律不变**：实验可以改参数（那是 Phase D 的事），但**每次改动必须 commit message 列明旧值→新值**，K3 验收时逐一对照。

### 12.2 实验流程（SOP）
```
提出假设（哪个参数/结构影响了哪类交易）
  → 改 1 处 + commit（旧值→新值写入 message）
  → 全窗口回放（同配置：4标的/15万/04-27~07-24）
  → 产出五件套：PDF + 3×CSV + backtrace
  → 对比表：KPI 四指标 + 通道分布 + 分标的盈亏 + 逐笔差异归因
  → K3 判定：✅采纳 / ⚠️边界（记录不采纳）/ ❌回退
  → 更新本文对应小节
```

### 12.3 判定阈值（建议）
- 收益改善 < +0.5pct 且回撤无改善 → 视为噪音，不采纳；
- MDD 恶化 > +1pct → 一票否决；
- 通道分布异常漂移（如 PANIC 次数翻倍）→ 必须解释才能采纳。

### 12.4 当前实验队列（按预期收益排序）
1. N25-3/N19/N20/N23 四个结构修复（WP-B0/B5'/B1'）——**这不是实验，是必修**；
2. 600176/603667 个股参数适配（复制 000988 的定制结构，初始值从全局出发）；
3. TRAIL 带界参数（MIN_BACK/k/MAX_BACK）在 fix2 场景的敏感性；

## 十四、路线图：从做T工具到量化神器

> **总纲**："神器"的定义不是预测得准，而是三条护城河——**① 纪律的机械化执行（人不干预）② 全链路可审计可归因（每笔盈亏知道为什么）③ 研究-验证-上线的快速迭代闭环**。以下每个阶段都以这三条为验收主线，不以"赚了多少"为阶段目标（收益是结果不是里程碑）。

### 阶段总览

| 阶段 | 时间（估） | 形态 | 一句话目标 |
|---|---|---|---|
| **R0 工具定型** | 现在 ~ 2026-08 | 模拟盘 | 行为正确、审计闭环、参数寻优完成 |
| **R1 实盘辅助** | 2026-09 ~ 10 | 模拟盘+实盘镜像 | 信号在实盘持仓上验证赚钱逻辑 |
| **R2 扩池组合** | 2026-11 ~ 12 | 小资金实盘 | 4 票 → 20~50 票，组合层接管资金分配 |
| **R3 多策略** | 2027-Q1 | 实盘 | 做T 之外接入第二、第三策略，策略间配资金 |
| **R4 平台化** | 2027-Q2 | 实盘 | 研究/回测/寻优/审计流水线化，周级迭代 |
| **R5 自进化** | 2027-H2+ | 实盘 | 复盘-归因-调参自动闭环，市场状态驱动策略切换 |

### R0 工具定型（当前阶段，Phase A~D 收尾）

- **剩余工作**：批次二（B0/B5'/B1'/B2'）→ Phase B 出口 → Phase C 组合层 → Phase D Optuna 寻优；
- **出口验收（硬指标）**：模拟盘连续 4 周：① 信号-成交一致率 >99%（无幻影/无漂移）；② 收益 >0 且 MDD <8%；③ 每日复盘无 P0/P1 级新缺陷连续 2 周；④ 三窗口回放包 + 通道分布表全量在案；
- **本阶段建成**：机械执行（护城河①）+ 审计归因（护城河②）。

### R1 实盘辅助（跟单级）

- **目标**：模拟盘持仓与实盘被套持仓镜像同步，策略信号经飞书推送后**人工执行**（或极小资金自动执行），验证信号在真实持仓上的赚钱效应；
- **关键动作**：① 实盘成交回填（真实滑点替代回测假设）；② 模拟-实盘行为偏差日报（同一信号两侧的成交差异）；③ 参数实盘化校准（滑点、流动性过滤进入 M2 门槛）；
- **出口验收**：实盘信号胜率与做T价差统计 ≥8 周可评估；模拟-实盘偏差可解释；**被套路解套进度可量化**（这是你最初的目标，在此阶段兑现）；
- **风险闸**：自动执行仅限小资金；大额仍需人工确认。

### R2 扩池与组合层

- **目标**：标的池 4 → 20~50，**打通你已有的三套资产**：三度猎手（每日扫描出信号票）→ 六维加权评分（质量排序）→ 韭研概念打分（板块热度）→ 入池 → 本系统执行；
- **关键动作**：① 个股参数**模板化**（按波动率/流动性分 3~4 档模板，替代逐票定制——否则 50 票 × 37 参数不可维护）；② 预算从等权改趋势加权（Phase C 遗留）；③ M3 组合状态机 + M6 相关性软约束上线；
- **出口验收**：池内任意票从"扫描入选"到"自动建底仓"全链路无人值守；组合层 KPI 体系（M5 五指标）每日自动产出。

### R3 多策略组合

- **目标**：做T 策略之外接入第二策略（候选：波段趋势、ETF 轮动——588170 的教训先解决 T+0/最小单位兼容），策略间按市场状态分配资金；
- **出口验收**：两策略相关性 <0.5，组合 MDD 低于任一单策略。

### R4 研究平台化

- **目标**：把第十二节"实验 SOP"产品化——因子库标准化、回测一键复现、Optuna 寻优流水线、参数版本管理（每次寻优结果落库可回溯）、自动周报；
- **出口验收**：一个新想法从假设到回放结论 <1 天；任何线上参数能回答"哪次实验、哪个窗口、什么证据把它定成这个值"。

### R5 自进化

- **目标**：每日复盘 → 归因 → 参数微调的闭环自动化（目前由你+我人工执行的 K3 审计循环，逐步 Agent 化）；市场状态识别（修复后的 index_regime + 个股状态机）驱动策略/参数档切换；
- **出口验收**：连续 1 个月无人工干预的自动迭代，且每一次自动改动都可审计、可回退。

### 风险与红线（全程有效）

1. **过拟合是头号敌人**：池子越大、窗口越多，参数才越可信；任何单窗口寻优结果不许直接上线；
2. **数据与接口依赖**：掘金仿真与实盘柜台行为差异、history_n 数据质量、飞书链路——每个都是单点，需有降级预案；
3. **合规红线**：个人账户自动化交易的券商接口边界，R1 起必须确认券商/监管对程序化交易的要求，不踩出借账户、不接外盘；
4. **资金纪律**：底仓 intact 框架、20% 现金底线——策略可以变，这两条不进入任何寻优空间。
