## 一、规则定义（owner 批准版，a-f 全按建议）

| 参数 | 定义 |
|---|---|
| a 离场范围 | **全仓**（含底仓，无地板豁免外的任何保留；遵守 T+1 可用量，当日买入锁定部分次日破位续卖） |
| b MA5 口径 | **静态值**：`daily_ctx["daily_ma5"]`（前 5 日收盘均值，main.py:580 已存在，日内不变，防反复横穿抖动） |
| c 当日禁令 | 破位日**禁一切买入**：BUY_LOW / buyback / BASE 建仓全部拦截 |
| d 次日及以后 | 每日独立判定：`price < 当日 daily_ma5` 即持续禁买+有余仓继续卖，直至 price 收复 MA5 自动解禁（MA5 每日刷新，天然实现） |
| e 通道优先级 | **最先执行**：MA5_EXIT > TRAIL_SELL > PANIC_SELL > 其他（趋势破坏优先级最高） |
| f buyback | MA5_EXIT 离场单**不生成** buyback armed（破位不回头；不得加入 `BUYBACK_SELL_ACTIONS`） |

**信号语义**：`MA5_EXIT`，score 固定 80（保护类同 TRAIL），reasons 示例 `"MA5破位离场: cp=54.66 < ma5=56.09 (-2.5%)"`。

## 二、代码改动点（锚点已核实）

### 1. 主通道（main.py）

- **插入位置**：TRAIL 段（main.py:1360）**之前**，优先级最高；
- **触发条件**：`daily_ctx.get("daily_ma5", 0) > 0 and cp < daily_ma5 and pos_qty > 0`；
- **定量**：`qty = 可用量`（全离，非 sizer 定量；遵守 T+1——今日新买锁定部分卖不出属预期，次日破位续卖）；
- **保护类登记**：`MA5_EXIT` 加入 main.py:119 `_is_protection` 名单（地板豁免、同 TRAIL/PANIC 语义）；
- **状态**：`context._ma5_broken[code] = "YYYY-MM-DD"`（破位日标记，供买侧禁令快速查询；落盘不必需，破位状态每日由 price vs 当日 MA5 动态重建）。

### 2. 买侧禁令（main.py 门控链末端，与 B-13 缓冲同层）

- 统一闸：`if daily_ma5 > 0 and cp < daily_ma5: 拦截全部买入意图`（BUY_LOW / buyback / BASE 一视同仁）；
- 留痕：backtrace `buy_blocks` 追加 `"ma5_break"` + 事件桥 `risk{kind=ma5_break_block, detail="cp=X < ma5=Y"}`（每票每日去重，防刷屏——与 O-13 同一去重框架）。

### 3. O-12：pos_key 容差匹配（main.py:812-815 INIT 校验）

- 拆解析 `qty@cost`：**数量不一致 → 作废**（原语义保留）；数量一致时**成本差 ≤ max(0.05 元, 0.5%) → 视为匹配并静默更新指纹**（吸收柜台 T+1 清算漂移，0818 案例 +0.002 元）；成本差超容差才作废留痕（防真实成本异常被吞）。

### 4. O-13：entry_gate 推送节流（watcher 侧）

- 同票同 `kind` 风控推送**每日首次推送 + 之后 30 分钟节流**（复用 B-15 mute 思路）；事件桥 jsonl 原文照写（审计流不减，只节推送）。
