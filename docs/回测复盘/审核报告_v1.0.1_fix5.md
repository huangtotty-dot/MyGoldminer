## 三、P0 新发现：N18 日线上下文跨票污染（本轮最重大问题）

### 现象
600481（双良节能）单手金额 6.26×100 = **626 元 < 2000 元门槛**，M2 门槛应拦截其底仓建仓；但 backtrace 显示 04-28 09:31 **四只票全部完成 base_order**（600481 1400 股 @6.26）。

### 根因（已定位）
`main.py:213-214`：

```python
today_str = now.strftime("%Y-%m-%d")
if getattr(context, "_daily_ctx_date", None) == today_str and hasattr(context, "daily_ctx_cache"):
    return context.daily_ctx_cache
```

**缓存键只有日期，没有股票代码。** `_refresh_daily_ctx` 每日被第一只处理的票（按 STOCKS 字典序 = **000988**，main.py:31-36）触发计算并缓存；同一天其余三只票（600481/600176/603667）全部拿到 **000988 的日线上下文**。

### 影响面（凡消费 daily_ctx 的逻辑全部失真）
| 受影响逻辑 | 消费字段 | 后果 |
|---|---|---|
| M2 门槛（A2） | `_m2_pool_pass/_m2_amp20/_m2_amount20/_m2_lot_value` | 600481 用 000988（单手 11,700 元）的指标过闸 → 验收失败 |
| R1 趋势熔断（A3） | `_stock_trend_state` | 603667 06-05 用 000988 的 TREND_UP 状态放行逆势买入 → 验收失败 |
| TREND_EXIT（B2） | `_stock_trend_state` | 非 000988 票的触发/不触发均不可信 |
| PANIC 触发线 | `daily_atr`（main.py:604 `max(-5×ATR, -12%)`） | 低价票用了 000988 的高波动率计算恐慌线 |
| 引擎日线特征 | `daily_ma5/10/20`、`daily_breakdown_risk`、`daily_overheated`、`daily_prev_close` | 买卖评分输入污染（影响面最广但难量化） |

### 审计结论修正
- 凡依赖 `_stock_trend_state` / `_m2_*` / `daily_atr` 的**行为级验收证据全部降级为"不可靠"**。A2/A3 判 ❌ 的直接原因即此。
- 不受污染的逻辑（结论仍有效）：TRAIL（用分钟价 cp 跟踪 peak）、成本锚 R2（profit_pct 由 holding cost 现算，main.py:601）、base_order、手续费、成交序列。
- 600481 的 5 次 PANIC（@5.42~5.50，亏损 ~12-13%）方向上与"用本票 ATR"的结论一致（trigger=-12% 两算同结论），属巧合性稳健，不具一般性。

### 修复建议（fix6 P0）
缓存键改为 `(日期, 代码)`：`context._daily_ctx_cache = {}` + 键 `f"{today_str}|{code}"`。改动 < 5 行，无阈值变化。**模拟盘上线前必修** —— 实盘场景下等于"用华工科技的趋势给双良节能做熔断决策"。
