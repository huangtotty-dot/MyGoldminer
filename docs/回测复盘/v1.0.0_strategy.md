# v1.0.0 — MACD 日内回转策略

> **标签**: `v1.0.0`
> **日期**: 2026-07-25
> **标的**: SZSE.000988 华工科技

---

## 策略概述

基于 1 分钟 K 线的 MACD 金叉/死叉信号进行日内回转交易（做 T）。底仓持有不动，利用 MACD 信号在日内高抛低吸，降低持仓成本。尾盘强制回转至初始仓位，确保持仓数量不变。

## 策略参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 标的 | `SZSE.000988` | 华工科技 |
| 底仓数量 | 5000 股 | 初始资金 20 万，股价约 25-35 元 |
| 每次交易量 | 300 股 | 日内回转交易单位 |
| K 线频率 | 60s | 1 分钟 Bar |
| MACD 参数 | SHORT=12, LONG=26, M=9 | 标准 MACD |
| 回看周期 | 100 根 Bar | 用于计算 MACD |

## 交易逻辑

### 1. 建底仓（首次触发）

首个 Bar 到来时，以市价单买入 `context.total`（5000 股）建立底仓，同时初始化手动仓位跟踪。

### 2. 尾盘回转（14:57 之后）

若当前持仓不等于底仓数量，以市价单强制回转至底仓数量，确保每日收盘仓位一致。

### 3. MACD 金叉买入（非尾盘时段）

条件：`macd[-2] <= 0` 且 `macd[-1] > 0`

即 MACD 柱状线由负转正，买入 300 股。

### 4. MACD 死叉卖出（非尾盘时段）

条件：`macd[-2] >= 0` 且 `macd[-1] < 0` 且可用仓位 >= 300 股

即 MACD 柱状线由正转负，卖出 300 股。

### 5. T+1 持仓结转

每天 09:31 将昨日持仓全部解冻为可用仓位，模拟 A 股 T+1 规则。

## 关键改动（相对掘金官方示例）

### 手动仓位跟踪

掘金量化 SDK 的 `get_position()` 在回测中对深交所（SZSE）股票不能正确返回仓位信息。因此改用 `context.pos_volume` / `context.pos_available` 字典手动跟踪：

- **买入时**：`pos_volume += trade_n`
- **卖出时**：`pos_volume -= trade_n`，同时 `pos_available -= trade_n`
- **T+1 结转**：每天 09:31 `pos_available = pos_volume`
- **尾盘回转**：`pos_volume = total`，`pos_available = total`

### 回测窗口限制

掘金量化基础版账号最多只能查询 180 个自然日的历史数据，`subscribe` 暖仓时还需额外预取 100 根 Bar。因此回测窗口设为 90 天。

## 运行方式

```bash
python main.py
```

回测区间为 `now() - 90天` 至 `now()`，结果通过终端输出查看。

## 局限与后续方向

- 单标的，仅基于 MACD 单一指标
- 无止损/止盈逻辑
- 无市场状态识别（单边行情中 MACD 频繁失效）
- 无信号评分 / 过滤机制
- 可用于验证掘金量化 SDK 回测管线的基本可用性，后续版本逐步引入信号引擎、风控、大盘态势识别等模块
