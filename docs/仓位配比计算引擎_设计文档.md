# 三段式仓位配比计算引擎 — 设计文档

> 版本：v1.0  
> 日期：2026-07-27  
> 用途：根据资金总量与持仓标的，按底仓 + 活动仓 + 现金三段式框架，输出各股票在不同行情下的购买数量范围建议。

---

## 一、项目概述

### 1.1 目标

开发一个 Python 脚本，实现以下闭环：

1. **输入**：用户资金总量、持仓股票列表、各股票最新价格。
2. **处理**：按三段式仓位框架（底仓 + 活动仓 + 现金）进行动态配比计算。
3. **输出**：生成 Excel 表格，展示每只股票在 **行情下行、行情震荡、行情上行** 三种场景下的建议购买数量范围。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **保守优先** | 底仓以 "intact（不动）" 为默认态，仅在极端条件下才触发减仓逻辑 |
| **弹性活动仓** | 活动仓用于做T高抛低吸，比例需保留弹性空间 |
| **现金底线** | 现金占比不得低于设定阈值（默认 20%），极端机会储备 |
| **行情敏感性** | 三种行情场景对应不同的加仓/减仓强度 |
| **粒度精确** | 购买数量以 "手（100股）" 或 "股" 为单位，避免零散碎股 |

## 二、业务背景与仓位框架

### 2.1 三段式仓位定义

根据用户的实际操盘体系，仓位划分为三个层次：

```
┌─────────────────────────────────────────────────────────┐
│                    资金总量（100%）                       │
├─────────────┬─────────────────────┬─────────────────────┤
│   底仓      │      活动仓          │       现金           │
│  50%~60%   │      20%~30%         │      20%（底线）      │
├─────────────┼─────────────────────┼─────────────────────┤
│ • 默认 intact │ • 高抛低吸做T       │ • 应对极端机会       │
│ • 极端偏高+  │ • 日内/波段交易      │ • 不跌破底线         │
│   基本面恶化 │ • 灵活调仓          │                     │
│   才减仓    │                     │                     │
└─────────────┴─────────────────────┴─────────────────────┘
```

### 2.2 各层级行为规则

| 层级 | 占比范围 | 行为规则 |
|------|----------|----------|
| **底仓** | 50% ~ 60% | 默认保持 intact，不轻易变动。仅在估值极端偏高且基本面边际恶化时，才考虑灵活减仓 |
| **活动仓** | 20% ~ 30% | 用于高抛低吸做T，根据行情方向调整仓位高低。行情上行时增加活动仓比例，下行时收缩 |
| **现金** | ≥ 20%（硬性底线） | 永远保留至少 20% 现金应对极端机会。即使行情极好，现金也不得跌破此线 |

### 2.3 行情场景定义

| 行情 | 定义 | 策略倾向 |
|------|------|----------|
| **行情下行** | 大盘/个股趋势向下，风险释放中 | 收缩活动仓，保守观望，减少买入或仅小仓位试盘 |
| **行情震荡** | 大盘/个股无明显方向，区间内波动 | 活动仓保持中等水平，利用波动做T |
| **行情上行** | 大盘/个股趋势向上，赚钱效应明显 | 增加活动仓，积极加仓，但仍保留现金底线 |

## 四、核心算法设计

### 4.1 算法流程图

```
开始
 │
 ├─→ 步骤1：读取输入（资金、持仓、价格）
 │
 ├─→ 步骤2：计算默认三段式分配
 │     ├─ 底仓金额 = total_capital × base_position_ratio
 │     ├─ 活动仓金额 = total_capital × active_position_ratio
 │     └─ 现金金额 = total_capital × cash_reserve_ratio
 │
 ├─→ 步骤3：遍历三种行情场景
 │     │
 │     ├─→ 步骤3.1：应用场景调整系数
 │     │     ├─ 调整后底仓 = 底仓金额 × (1 + base_adjustment)
 │     │     ├─ 调整后活动仓 = 活动仓金额 × (1 + active_adjustment)
 │     │     └─ 调整后现金 = 现金金额 × (1 + cash_adjustment)
 │     │
 │     ├─→ 步骤3.2：校验约束条件
 │     │     ├─ 现金 ≥ total_capital × 0.20 （硬性底线）
 │     │     ├─ 底仓 + 活动仓 + 现金 = total_capital
 │     │     └─ 若超限，按优先级回退：现金 > 底仓 > 活动仓
 │     │
 │     ├─→ 步骤3.3：按股票分配购买金额
 │     │     ├─ 策略A：等权重分配（默认）
 │     │     ├─ 策略B：按风险等级加权（高风险少配，低风险多配）
 │     │     └─ 策略C：按板块集中度控制（单板块不超过 X%）
 │     │
 │     └─→ 步骤3.4：计算购买数量范围
 │           ├─ 单股金额 = 分配金额 × buy_intensity
 │           ├─ 购买数量 = floor(单股金额 / 当前价格 / 100) × 100
 │           └─ 范围 = [购买数量 × 0.5, 购买数量 × 1.5]（上下浮动50%）
 │
 ├─→ 步骤4：整合三种场景结果
 │
 └─→ 步骤5：输出 Excel 表格
```

### 4.2 关键算法详解

#### 4.2.1 场景调整后的资金分配

```
对于每种行情场景：

adjusted_base = total_capital × base_position_ratio × (1 + scenario.base_adjustment)
adjusted_active = total_capital × active_position_ratio × (1 + scenario.active_adjustment)
adjusted_cash = total_capital × cash_reserve_ratio × (1 + scenario.cash_adjustment)

# 约束校验与归一化
total_allocated = adjusted_base + adjusted_active + adjusted_cash

if adjusted_cash < total_capital × 0.20:
    # 现金跌破底线，强制拉回
    adjusted_cash = total_capital × 0.20
    # 差额从活动仓扣除，底仓尽量不动
    deficit = total_capital × 0.20 - adjusted_cash
    adjusted_active -= deficit
    if adjusted_active < 0:
        # 活动仓不够扣，再扣底仓（极端情况）
        adjusted_base += adjusted_active  # adjusted_active 为负
        adjusted_active = 0

# 最终归一化，确保总和严格等于 total_capital
final_total = adjusted_base + adjusted_active + adjusted_cash
if abs(final_total - total_capital) > 0.01:
    # 按比例缩放
    scale = total_capital / final_total
    adjusted_base *= scale
    adjusted_active *= scale
    adjusted_cash *= scale
```

#### 4.2.2 活动仓到单股票的金额分配

**策略A：等权重分配（默认）**

```
stock_count = len(holdings)
if stock_count == 0:
    return 空结果

# 每只股票的活动仓金额
per_stock_active = adjusted_active / stock_count

# 应用买入强度（场景相关）
per_stock_buy_amount = per_stock_active × scenario.buy_intensity
```

**策略B：风险等级加权分配（可选）**

```
# 风险等级映射到权重
risk_weights = {
    "low": 1.5,      # 低风险多配
    "medium": 1.0,   # 中风险标配
    "high": 0.5      # 高风险少配
}

# 计算总权重
total_weight = sum(risk_weights[s.risk_level] for s in holdings)

# 每只股票的活动仓金额
for stock in holdings:
    weight = risk_weights[stock.risk_level]
    stock_active = adjusted_active × (weight / total_weight)
    stock.buy_amount = stock_active × scenario.buy_intensity
```

**策略C：板块集中度控制（可选）**

```
# 先按等权重或风险加权分配
# 然后检查板块集中度
sector_limits = {
    "半导体": 0.30,        # 半导体板块不超过活动仓的 30%
    "存储芯片": 0.20,
    "先进封装": 0.15,
    "光刻机": 0.15,
    "锂电池": 0.20,
    "AI_PCB": 0.15
}

# 若某板块超限，将超额部分 redistribute 到其他板块
```

#### 4.2.3 购买数量计算

```
# 单只股票可购买金额
buyable_amount = per_stock_buy_amount

# 考虑已有持仓（底仓逻辑）
# 底仓部分 = adjusted_base / stock_count（等权重）
base_amount_per_stock = adjusted_base / stock_count

# 活动仓部分 = buyable_amount

# 总建议持仓金额 = 底仓金额 + 活动仓金额
total_position_amount = base_amount_per_stock + buyable_amount

# 换算成股数（向下取整到100的倍数）
suggested_shares = floor(total_position_amount / stock.current_price / 100) × 100

# 计算购买数量范围（上下浮动 50%，作为操作建议区间）
min_shares = floor(suggested_shares × 0.5 / 100) × 100
max_shares = ceil(suggested_shares × 1.5 / 100) × 100

# 若已有持仓，计算需增仓数量
if stock.existing_shares > 0:
    additional_shares = max(0, suggested_shares - stock.existing_shares)
    additional_range = [max(0, min_shares - existing), max(0, max_shares - existing)]
```

#### 4.2.4 范围生成的业务逻辑

| 行情 | 范围浮动比例 | 理由 |
|------|-------------|------|
| 下行 | [0.3, 0.8] | 保守，下限低（可空仓观望），上限也低 |
| 震荡 | [0.5, 1.2] | 中性，允许一定弹性 |
| 上行 | [0.8, 1.5] | 积极，下限高（至少打一定仓位），上限放开 |

## 附录：核心公式速查

```
资金总量 = C
底仓比例 = b，活动仓比例 = a，现金比例 = c （b + a + c = 1）

场景调整后：
  B' = C × b × (1 + base_adj)
  A' = C × a × (1 + active_adj)
  C' = MAX(C × c × (1 + cash_adj), C × 0.20)

归一化：
  S = B' + A' + C'
  B = B' × C / S
  A = A' × C / S
  CASH = C' × C / S

单股分配（等权重，n 只股票）：
  base_per_stock = B / n
  active_per_stock = A / n × buy_intensity

股数计算（价格 P）：
  base_shares = FLOOR(base_per_stock / P / 100) × 100
  active_shares = FLOOR(active_per_stock / P / 100) × 100
  total_shares = base_shares + active_shares

范围（multiplier = [m1, m2]）：
  min_shares = FLOOR(total_shares × m1 / 100) × 100
  max_shares = CEIL(total_shares × m2 / 100) × 100

需增仓（existing = E）：
  additional = MAX(0, total_shares - E)
```
